Photos and videos without a database or cloud

Choose the root folder of your media library (not __gallery itself). The gallery finds photos and videos in subfolders. Favorites, albums, tags and the file index are human-readable files in __gallery/. Thumbnails are stored in __gallery/thumbs/.

Works in Chrome and Edge. Your photos never leave your computer.

Shortcuts: ← → navigate (when the video player is not focused), F favorite, Esc close, / search. Click outside the photo/video to close.

Detected moves and renames

Select the file moves for which favorites, tags, and album entries should be transferred to the new paths. Original media files are untouched. A metadata backup is saved first.
