Photos and videos without a database or cloud

Choose the root folder of your media library (not __gallery itself). The gallery finds photos and videos in subfolders. Favorites, albums, tags and the file index are human-readable files in __gallery/data/. Thumbnails are stored in __gallery/data/thumbs/.

Works in Chrome and Edge. Your photos never leave your computer.

In-gallery Trash hides this file but keeps the original on disk. Permanent deletion bypasses your operating system's Recycle Bin.

Shortcuts: ← → navigate (when the video player is not focused), F favorite, Esc close, / search. Click outside the photo/video to close.

Detected moves and renames

Select the file moves for which favorites, tags, and album entries should be transferred to the new paths. Original media files are untouched. Approved changes are saved immediately.

Permanently delete?

This permanently deletes original files from disk. It does not use your system's Recycle Bin/Trash. No backups will be created.
