# Demo media library

This folder contains 16 offline SVG sample illustrations, plus sample favorites, tags, and albums. Images are original demonstration artwork and contain no personal data.

To try it after cloning this repository:

1. Open `../__gallery/index.html` in **Chrome or Edge**.
2. Click **Open library** and choose this **demo-gallery** folder.
3. Allow local folder access. The first scan builds the index in `demo-gallery/__gallery/data/`.
4. Test Classic/Instagram mode, multi-selection, tags, albums, favorites, and the maintenance controls.

Everything happens locally. The generated index and preview files in the demo data folder are ignored by Git. Do not use permanent deletion on demo media unless you intend to delete those example files.

This demo is intentionally separate from the actual gallery source `../__gallery/index.html`.

This demo contains 18 albums (including long names) and a larger tag catalog for testing scrolling and selection.
